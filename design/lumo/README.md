# Lumo brand files

Lumo is a made-up brand the demo uses to show a customer's own look. These files are uploaded in the
ProofAge console (Branding tab) of the three Lumo workspaces: Selfie Lumo, Age by ID Lumo and KYC Lumo.

| File | Use |
|---|---|
| `lumo-logo.svg`, `lumo-logo.png` (454×512) | Logo: a rounded "L" with a dot of light. The PNG is what is uploaded. |
| `lumo-favicon.svg`, `lumo-favicon-256.png`, `lumo-favicon-64.png`, `lumo-favicon-32.png` | Favicon: the same mark, white on a rounded tile. The 256 px PNG is what is uploaded: the widget also puts the favicon in the middle of its QR code, where 64 px came out pixelated. |

Colour `#3052B9` on the background `#EEF1FA`, as set in the console. The previews in `public/flow/*-lumo-*.webp`
show this logo.
